# Discovery meeting — FitTrack Studios

Fictional transcription authored for this repository as the exercise input (see design.md, Open Questions).

Laura (Client, Operations Director): Thanks for joining. We run four fitness studios in Madrid and we're growing to six next year. Right now members book classes through a mix of WhatsApp and a spreadsheet, and it's chaos.
Marco (Agency, PM): Understood. What would you like members to be able to do?
Laura: Members should be able to see the class schedule and book or cancel a spot from their phone. If a class is full, they should join a waitlist and get notified when a spot opens.
Marco: Web, mobile app, or both?
Laura: We want a mobile app for members, iOS and Android. Our front-desk staff will use a web panel on the reception computer.
Marco: What does the staff panel need?
Laura: Staff need to create classes, assign instructors, and check members in when they arrive. I also want a dashboard with occupancy per class and per studio.
Diego (Client, Finance): On payments: members buy monthly memberships or 10-class packs. They should pay by card inside the app. We already use Stripe for our online shop.
Marco: Any existing systems we need to connect to?
Diego: Our accounting is in Holded. It would be great if payments showed up there automatically, but that's a nice-to-have.
Laura: One more thing: instructors should get a list of who's booked for their next class.
Marco: Any timeline?
Laura: We'd like to launch before September, when the new season starts.
Marco: And what about existing member data?
Laura: We have about 2,000 active members in the spreadsheet. We need to import them.
Marco: Anything about languages?
Laura: Spanish for sure. English would be nice for our international members.
Marco: Great, we'll come back with an estimate.
